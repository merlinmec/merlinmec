### Sobre

Desenvolvedor backend Java em Teresina (PI). Trabalho desde 2023 no **Edu3**,
um sistema de gestão escolar usado por mais de 30 escolas: entrei como
estagiário e fui efetivado em novembro de 2024. Meu trabalho é o que não
aparece na tela:

- **Migração de dados:** trouxe os dados de 2012 a 2026 do sistema legado de uma escola (~1 milhão de notas, 9.000 inscrições), com rotina de reversão.
- **Desempenho:** reescrevi as buscas pesadas com projeções no Hibernate. Uma delas chegava a derrubar o sistema.
- **Integrações:** catracas com reconhecimento facial (gateway Java que funciona sem internet), Censo Escolar validado contra o layout oficial do INEP (494 campos) e assinatura digital com Clicksign.

Nos projetos próprios uso a stack que o mercado pede hoje: Java 21, Spring Boot,
PostgreSQL e testes de integração com Testcontainers.
